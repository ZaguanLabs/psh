# psh 1.0.0-rc4

psh is a performance fork of Zsh 5.9.2 built for heavy interactive and
application workloads inside the shell. **1.0.0-rc4** delivers ten deep
interpreter optimization rounds (rounds 101–110) targeting arithmetic
evaluation, UTF-8/ASCII text scanning, parameter expansion, hash table lookup,
option emulation, and arena reuse — achieving **1.10×–2.72×** speedups over
`1.0.0-rc3` and **1.63×–4.67×** over pristine Zsh 5.9.2 across all 15 tracked
application workloads, while cutting heap allocation churn by **47%–86%** and
introducing **zero new deliberate incompatibilities**.

## Highlights since rc3

### Arithmetic engine & bytecode caching (rounds 106, 108, 110)
- **Two-tier compiled integer bytecode VM** (`Src/math.c`): Repeated pure-ASCII
  integer arithmetic expressions compile into compact RPN bytecode inside a
  bounded static-BSS cache (128 compact 80-byte/48-op slots + 8 large
  384-byte/192-op slots) using Zsh's own `c_prec`/`z_prec` and `type[]` tables.
  Variables are deduplicated and cached per execution, compound assignments
  preserve Zsh's exact RHS-before-LHS evaluation order, and non-integer or
  error cases bail out without side effects and auto-demote cleanly.
- **Wordcode-site pointer cache** (`Src/exec.c`, `Src/loop.c`, `Src/parse.c`):
  Literal `(( ... ))` and `for (( ... ))` sites in permanent wordcode resolve
  directly through a 128-entry pointer cache invalidated by `psh_eprog_gen` on
  `freeeprog()`, skipping `ecgetstr()` copying, expression hashing, and
  `memcmp()` on warm loop iterations.
- **Rounding-mode-exact float literal cache & fast math lexing** (`Src/math.c`):
  Single-pass decimal integer lexing, borrowed plain-ASCII identifiers with
  direct `PM_INTEGER`/`PM_FFLOAT`/`PM_EFLOAT`/plain-decimal `PM_SCALAR` access,
  outer-only signal queueing, an iterative 64-entry operator stack, exact
  integer-valued float conversion, and a 64-entry rounding-mode-keyed float
  literal cache guarded on `uselocale((locale_t)0) == LC_GLOBAL_LOCALE`.
- **Direct `mathevalarg()` fast path**: Simple integer and single-identifier
  array subscripts resolve without entering the full parser or bytecode cache.

### UTF-8 decoding, ASCII scanning & parameter expansion (rounds 102, 103, 109)
- **Fast simple parameter expansion** (`Src/subst.c`): Plain `$var`, `"$var"`,
  `${var}`, `"${var}"`, and `$1`..`$9` expansions for standard scalars and
  base-10 integers bypass `paramsubst()`'s full frame and `strcatsub()`, while
  `stringsubst()` skips `strchr`/`strcspn` scans on pure-ASCII spans.
- **Direct RFC 3629 UTF-8 decoding & SWAR ASCII scanning** (`Src/utils.c`,
  `Src/pattern.c`): `mb_metacharlenconv_r()`, `mb_metastrlenend()`, and pattern
  character iteration decode strictly valid RFC 3629 UTF-8 directly when
  `nl_langinfo(CODESET)` is UTF-8, falling back to `mbrtowc()` for non-UTF-8,
  shift-state, invalid, or libc-extended sequences.
- **Fast ASCII identifier scanning** (`Src/utils.c`): `itype_end()` scans pure
  ASCII `IIDENT` prefixes directly and defers `mb_charinit()`.

### Hash tables, options, arrays & heap reuse (rounds 101, 104, 105, 107)
- **Power-of-2 hash tables & fast probing** (`Src/hashtable.c`, `Src/params.c`,
  `Src/builtin.c`, `Src/options.c`, `Src/hashnameddir.c`): Default initial
  bucket counts use powers of two, with inline `hasher`, bitmask indexing, and
  first-byte key prechecks on standard tables (`hasher` + `strcmp`).
- **Precomputed option-emulation masks & conditional `inittyptab()`**
  (`Src/options.c`, `Src/builtin.c`): `installemulation()` applies precomputed
  option masks, and `setopt`/`set` only rebuild `typtab` when `MULTIBYTE` or
  `BANGHIST` actually changes.
- **Array prefix reuse & plain-ASCII subscript lexing** (`Src/params.c`,
  `Src/lex.c`): In-place array updates beyond index 32 reuse cached confirmed
  prefixes, and non-ZLE double-quoted/subscript lexing uses a fast ASCII table.
- **Pooled `cmdstack` & heap arena reuse** (`Src/prompt.c`, `Src/mem.c`,
  `Src/exec.c`, `Src/hist.c`, `Src/init.c`): `cmdstack` buffers draw from an
  8-slot static pool, nested `new_heaps()`/`old_heaps()` preserve outer rewind
  extents, and `freeheap()` moves nearly full pushed arenas ahead of `fheap`
  without adding branches to `zhalloc()`.

### Memory & allocation footprint (`v1.0.0-rc3` → `v1.0.0-rc4`)

- **DHAT total `malloc` churn**: `endgame-world` 16.78 → **2.40 MiB (−85.7%)**,
  `chat-paste` 26.52 → **10.59 MiB (−60.1%)**, `coder-wide-layout` 24.88 →
  **13.16 MiB (−47.1%)**.
- **Linux `/proc` 20-cycle medians**: `[heap]` RSS dropped 24 KiB on sustained
  `endgame-world` (1,072 → **1,048 KiB**) and remained flat (+4 KiB) across
  `coder-wide-layout`, `chat-paste`, and `mario-race`. Private anonymous RSS
  increased by 40–76 KiB (`VmSize` +108–112 KiB) from bounded fixed-capacity
  static-BSS caches (~73 KiB total, zero unbounded heap growth across 20 cycles).

## Compatibility

No new deliberate behavioral departures were introduced in `1.0.0-rc4`. All
existing documented differences remain listed in
[COMPATIBILITY.md](../COMPATIBILITY.md). Differential and native verification
against pristine Zsh 5.9.2 passed with zero mismatches and zero Memcheck errors:

- **267,776** math-locale & IEEE-754 rounding-mode checks (`33,472 × 8` locales,
  native + Memcheck)
- **15,300** arithmetic differential cases across 5 locales + **144** stack
  storage cases + native math counter Memcheck fixture
- **538,428 × 2** hash-table, **120,312 × 2** hash-scan, and **31,003 × 2**
  `remnulargs` Memcheck checks
- **2,640** substitution and **14,364** pattern differential checks
- **14,237** `zjson` checks in `C` and `C.UTF-8`
- **63/63** upstream Zsh test scripts (`make check`)

## Build and install

Use the attached `psh-1.0.0-rc4.tar.xz` and verify it with `SHA256SUMS`.
The attached archive includes the verified upstream baseline used by the
build tools.

```sh
tar -xf psh-1.0.0-rc4.tar.xz
cd psh-1.0.0-rc4
python3 Perf/build.py --which candidate --profile release
./psh --version
```

The [packaging guide](../Packaging/README.md) covers the isolated installation,
PGO/LTO builds (`python3 Packaging/build.py --optimization pgo-lto`),
startup environment, verification and rollback. The six bundled projects ship
through the package workflow. `psh --version` reports
`psh 1.0.0-rc4 (zsh 5.9.2)`, while `$ZSH_VERSION` remains `5.9.2`. Build
external native modules against the SDK for the package you install.
