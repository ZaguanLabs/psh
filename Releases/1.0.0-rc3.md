# psh 1.0.0-rc3

psh is a performance fork of Zsh 5.9.2. This candidate reduces temporary
allocations and copying in arithmetic, pattern matching, shell calls and
string expansion. It also tightens argument handling in system and terminal
builtins.

## Changes since rc2

- Arithmetic variable reads that an operator consumes immediately use a
  temporary descriptor on the C stack. Compound assignment retains the
  descriptor needed to write back through the original subscript.
- Long literal patterns can be matched directly against expanded operands
  in one-shot conditions. Cached and native pattern programs retain their
  own storage. Expansion also skips clearing buffers that it immediately fills.
- Large scalar appends can grow owned values in place. Array shifts and shell
  calls copy less, and the temporary heap can reuse cleared mappings across
  scopes. On glibc, the interactive shell can release large unused allocator
  arenas before returning to the prompt.
- System, socket and terminal commands validate out-of-range descriptors and
  numeric arguments before passing them to the OS. Some invalid inputs now
  fail earlier. The affected commands and cases are in the
  [compatibility notes](../COMPATIBILITY.md).

## Measurements

Round 100's independently trained PGO/LTO build was 2.11× as fast as pristine
Zsh on zcoder paste, 2.13× on zchat paste and 1.43× on Endgame world generation.
Endgame took 2.1–2.7% longer than round 99 in two run orders. These comparisons
time specific project operations and verify their final state. The published
source can also be built with the standard compiler profile.

In a 65,536-read arithmetic expression, anonymous resident memory grew by
396 KiB during evaluation, down from 2,964 KiB on round 99 and 2,960 KiB on
pristine Zsh. In sustained Endgame, the resident main heap stayed at
1,068 KiB. See the [round 100 report](../Perf/round100.md) for the workload,
measurement details and compatibility checks.

## Build and install

Use the attached `psh-1.0.0-rc3.tar.xz` and verify it with `SHA256SUMS`.
The attached archive includes the verified upstream baseline used by the
build tools.

```sh
tar -xf psh-1.0.0-rc3.tar.xz
cd psh-1.0.0-rc3
python3 Perf/build.py --which candidate --profile release
./psh --version
```

The [packaging guide](../Packaging/README.md) covers the isolated installation,
startup environment, verification and rollback. The six bundled projects ship
through the package workflow. `psh --version` reports
`psh 1.0.0-rc3 (zsh 5.9.2)`, while `$ZSH_VERSION` remains `5.9.2`. Build
external native modules against the SDK for the package you install.
